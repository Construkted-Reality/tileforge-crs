## F1 — `to_ecef` silently returned `Ok([NaN, …])` for non-finite geographic input

Defect: proj4rs validates latitude but passes a non-finite **longitude** or **height**
straight through for geographic sources, so `to_ecef([NaN, 45, 0])` returned
`Ok([NaN, NaN, 4487348.408865919])` (RED evidence, verbatim). The identity (EPSG:4978)
short-circuit likewise copied `NaN` through. One poisoned vertex silently corrupts every
downstream bbox/centroid — the exact silent-corruption class this crate exists to prevent.

Fix: validate all three axes with `is_finite()` at the top of `to_ecef`, ahead of the
identity short-circuit, returning `CrsError::Reproject` naming the offending triple. Applies
uniformly to geographic, projected, and identity sources. Finite inputs are unchanged
(both parity grids stay <1 µm; identity stays bit-equal for finite input).

Test: `reproject::tests::non_finite_input_is_rejected` — folds in MT3 (each axis ×
{NaN, +inf, -inf} × {4326 geographic, 32617 projected, 4978 identity}), all assert `is_err()`.

Consumer grep (mesh + pc): all `to_ecef` call sites propagate the result via `?` /
`.map_err(...)`; none rely on the old `Ok(NaN)` pass-through. Safe to tighten Ok→Err.

## F2 — degenerate / non-finite ECEF origins silently accepted

Defect: proj4rs's geocentric inverse maps `[0,0,0]` to the north pole
(`Ok((0.0, 1.5707963267948966))`, review probe verbatim) and passes NaN through, so
`EnuFrame::from_ecef_origin` would anchor a whole tileset at the wrong place with no error
anywhere — the hardest failure mode to diagnose downstream. RED reproduced locally with the
guard disabled: `ecef_to_geodetic_lonlat([0,0,0])` returned Ok.

Fix: guard `ecef_to_geodetic_lonlat` (which `from_ecef_origin` calls first) against non-finite
input and against an implausibly small radius (`< MIN_ECEF_RADIUS_M = 6.2e6 m`; Earth's polar
radius is ~6.357e6 m, so any real surface anchor clears it). Both entry points now reject the
geocenter, deep-interior points, and non-finite origins with `CrsError::Reproject`.

Tests: `enu::tests::degenerate_or_non_finite_origin_is_rejected` (F2 RED→GREEN);
`ecef_to_geodetic_lonlat_recovers_known_lon_lat` + `basis_is_orthonormal_at_extreme_anchors`
fold in MT4 (direct value assert + poles/both-hemispheres/antimeridian coverage).

Consumer grep (mesh + pc): all `from_ecef_origin` / `ecef_to_geodetic_lonlat` call sites
propagate via `?` / `.map_err(...)`; none relied on the old degenerate pass-through.
